# Test1 — Инструкция 1: Запись теста авторизации

## Что требовалось по ТЗ

- Установить браузер (Chrome/Firefox) и Selenium IDE / Katalon
- Записать тест авторизации рекордером
- Экспортировать записанный тест в код на языке программирования
- Убедиться что тест запускается

## Что сделано

Записан тест авторизации в Katalon (`test1.py`) и переведён на Go.

### Файлы

| Файл | Описание |
|---|---|
| `login_test.go` | Единственный файл — прямой перевод `test1.py` на Go |

### Структура теста (зеркало test1.py)

```
setUp      — запуск ChromeDriver, настройка implicit wait 30s, base_url
test       — открыть /login → ввести логин → ввести пароль → нажать submit → перейти на /
tearDown   — закрыть браузер, проверить verificationErrors
```

### Что намеренно НЕ сделано

- Никаких хелперов и базовых классов — всё в одном файле
- Никакого рефакторинга — код как есть после рекордера

## Запуск

```bash
go test -v -count=1 ./...
```
