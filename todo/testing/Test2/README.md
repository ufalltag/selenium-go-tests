# Test2 — Инструкция 2: Рефакторинг кода

## Что требовалось по ТЗ

- Вынести повторяющиеся шаги в отдельные методы (GoToLoginPage, Login, CreateTodo и др.)
- Создать базовый класс `TestBase` с методами `SetUp` и `TearDown`
- Создать классы для объектов сайта: `AccountData`, `TodoData`
- Добавить второй тест — на добавление сущности (задачи)

## Что сделано

### Файлы

| Файл | Описание |
|---|---|
| `models.go` | Классы данных: `AccountData` (логин/пароль), `TodoData` (название/дедлайн) |
| `test_base.go` | `TestBase` — базовый класс с `SetUp`, `TearDown` и вспомогательными методами |
| `login_test.go` | Тест авторизации — использует методы из `TestBase` |
| `todo_test.go` | Второй тест — создание задачи |

### Вынесенные методы в TestBase

```
GoToLoginPage()   — переход на страницу входа
GoToMainPage()    — переход на главную страницу
Login(user)       — авторизация через AccountData
CreateTodo(todo)  — создание задачи через TodoData
IsElementPresent  — проверка наличия элемента на странице
```

### Что намеренно НЕ сделано

- Нет хелпер-классов (NavigationHelper, AuthHelper и др.) — это Инструкция 3
- Нет AppManager — это Инструкция 3
- Каждый тест создаёт свой `TestBase` (свой браузер)

## Запуск

```bash
go test -v -count=1 ./...
```
